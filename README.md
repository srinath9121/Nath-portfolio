# 🖥️ Nath.Portfolio — NathOS

A retro Windows 98-inspired interactive portfolio built with pure Vanilla HTML, CSS, and JavaScript.

🌐 **Live Demo:** [srinath9121.github.io/Nath-portfolio](https://srinath9121.github.io/Nath-portfolio/)

---

## ✨ Features

- **🪟 Windows 98 Desktop:** Fully draggable, resizable, minimizable, and maximizable windows with custom z-indexing.
- **🤖 Data Clippy AI Assistant:** Retro assistant with an interactive 3-step guided tour and random data science tips.
- **💻 Interactive Terminal (`C:\`):** Terminal emulator with commands like `cat resume.txt`, `whoami`, `matrix`, `weather`, and `sudo`.
- **🎨 Desktop Theme Switcher:** 4 wallpaper styles (Windows XP Bliss, Windows 98 Classic Teal, Cyberpunk Dark, Matrix Green) saved to `localStorage`.
- **🎵 Spotify Player:** Built-in retro music player.
- **🐍 Snake Game:** Playable mini-game with high score persistence.
- **🎮 Konami Code Easter Egg:** Press `↑ ↑ ↓ ↓ ← → ← → B A` for a 360° desktop flip & secret badge.
- **🔊 Sound Synthesizer:** Custom Web Audio API 8-bit sound effects with a taskbar mute toggle.

---

## 🛠️ Tech Stack

- **Core:** Pure HTML5, Vanilla CSS3, Vanilla JavaScript (Zero framework dependencies)
- **Audio:** Web Audio API (Synthesizer sound effects)
- **Graphics:** HTML5 Canvas (Real-time ML curve simulation)
- **Backend (Optional):** [Supabase](https://supabase.com) for contact messages & visitor counter
- **Fonts:** MS Sans Serif, Courier New, Google Fonts (*Press Start 2P*)

## 🚀 Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/srinath9121/Nath-portfolio.git
   cd Nath-portfolio
   ```

2. **Run locally:**
   Simply open `index.html` in any web browser — no build tools or package managers required!
